# Document-signature-app

A web application to upload PDF files, add signatures, and generate signed PDF documents.

## Features
- Upload PDF files
- View uploaded PDFs
- Add signature
- Drag and position signature
- Generate signed PDF
- Download signed PDF

## Tech Stack

### Frontend
- React
- React Router

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### PDF Processing
- PDF-Lib

## API Endpoints

- POST /upload
  - Upload PDF file

- POST /sign
  - Save signature and generate signed PDF

- GET /uploads/:filename
  - View uploaded and signed PDF
